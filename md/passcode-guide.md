바로온장은 지인과 관계자에게 시연하기 위한 MVP야.

복잡한 회원 인증 시스템을 만들지 말고, 운영자가 직접 발급하는 초대코드 방식으로 구현해 줘.

- 초대코드는 3개만 수동 등록한다.
- 각 코드에는 고유한 사용자 ID를 연결한다.
- 코드를 입력하면 서버에서 확인하고 해당 사용자의 화면으로 이동한다.
- 코드마다 상품 1개를 등록할 수 있다.
- 자신의 상품이 있으면 마이페이지에 QR코드를 표시한다.
- 상품이 없으면 시작하기 버튼을 표시한다.
- 회원가입, 이메일 인증, Supabase Auth, 관리자 페이지는 구현하지 않는다.
- 초대코드는 브라우저 소스에 노출되지 않도록 한다.
- 인증 상태는 간단한 세션 쿠키로 유지한다.
- 시연용 MVP이므로 불필요한 인증 기능이나 복잡한 구조는 추가하지 않는다.

### 초대코드 저장 및 등록

- 초대코드 원문은 Supabase에 저장하지 않고 Argon2id 해시로 저장한다.
- 운영자가 직접 만든 초대코드 3개를 해시로 변환하여 Supabase에 등록할 수 있는 간단한 로컬 실행 스크립트를 작성한다.
- 별도의 코드 발급·관리 화면은 만들지 않는다.
- 실제 초대코드는 소스코드나 Git 저장소에 포함하지 않는다.
- 서버에서는 입력한 초대코드를 저장된 해시와 비교하여 해당 사용자 ID를 확인한다.
