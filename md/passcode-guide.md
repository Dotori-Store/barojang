Passcode### 인증코드 및 사용자 구분 정책 변경

기존 단일 공통 인증코드 정책을 변경한다.

- 회원가입 및 일반 로그인 기능은 구현하지 않는다.
- 운영자가 수동 발급한 인증코드 3개만 사용한다.
- 인증코드는 서버에서 검증하며 원문을 프런트엔드에 노출하지 않는다.
- 각 인증코드에는 고유한 사용자 ID를 연결한다.
- 인증 성공 시 해당 사용자 ID를 포함한 서버 검증 가능 세션을 발급한다.
- 상품 데이터는 사용자 ID를 기준으로 분리한다.
- 각 사용자 ID는 상품을 최대 1개만 생성할 수 있다.
- 상품 등록 및 마이페이지 API에서는 세션의 사용자 ID를 검증한다.
- 마이페이지에는 자신의 QR코드만 표시한다.
- 상품이 없다면 시작하기 버튼만 표시한다.
- 상품 소개 페이지는 누구나 접근할 수 있다.
- 코드 발급 및 관리 화면은 구현하지 않는다.
- 실제 인증코드 3개는 운영자가 직접 생성하고 등록한다.
- 인증코드 원문은 저장하지 않고 안전한 해시로 관리한다.
- 인증 요청에 횟수 제한을 적용한다.

기존 토큰 및 코인 차감 정책은 적용하지 않는다. 남은 코인 수치는 화면에만 임시로 표시한다.
